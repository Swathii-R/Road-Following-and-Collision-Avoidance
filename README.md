# Road Following and Collision Avoidance

## Overview

This project focuses on developing a robot that can follow a road path and avoid obstacles using sensors and Python programming.

**Topics Covered**

- Road Following
- Collision Avoidance
- Obstacle Detection
- Robot Motion Control

**Learning Outcomes**

- Road Following: Learned the basics of guiding a robot along a road path.
- Collision Avoidance: Understood how a robot detects and avoids obstacles.
- Robot Control: Learned the fundamentals of robot movement and programming.

**Technologies Used**

- Python Programming
- Robotics
- Sensors

**Conclusion**

This project helped me understand the basic concepts of road following, obstacle detection, and collision avoidance in robotics.
